# Контора: прототип звонков с ИИ (Godot 4, 2D)

## Скачать APK
Готовая сборка для Android: [apk/kontora-0.13.apk](https://github.com/kokazolik/scumai/raw/main/apk/kontora-0.13.apk).
Открой ссылку с телефона, установи (разреши установку из неизвестных источников), при первом запуске скопируй ключ OpenRouter и нажми «Ключ ИИ» → «Вставить ключ из буфера».

## Как запустить
1. Открой папку в Godot 4.3+ (Import → `project.godot`).
2. Дай игре ключ OpenRouter одним из способов:
   - переменная окружения `OPENROUTER_API_KEY`;
   - файл `secrets.cfg` в папке пользователя Godot (`user://`, в Windows это
     `%APPDATA%\Godot\app_userdata\Контора\`):
     ```
     [openrouter]
     api_key="sk-or-v1-..."
     ```
   Не клади ключ в папку проекта: он уедет в git и в собранную игру.
3. Запусти (F5). Откроется главное меню, «Начать работу» принимает первый звонок.

## Как устроено
- `scripts/openrouter_client.gd` — автозагрузка `LLM`, `await LLM.chat(messages)`.
- `scripts/callers.gd` — запасные профили звонящих. Обычно клиентов придумывает нейронка (`Callers.generate`),
  примерно каждый третий — пародия на известного персонажа (Балк, Граф Мрякула и т. п.).
- `scripts/shift_recap.gd` — все разговоры смены записываются, в конце нейронка выбирает 3-5 смешных моментов.
- Голос: `scripts/voice_recorder.gd` пишет WAV 16 кГц, `LLM.transcribe()` распознаёт его бесплатным Whisper от Groq
  (ключ `gsk_...` вставляется в меню «Ключи»). Без ключа кнопка микрофона открывает диктовку клавиатуры.
- Прогресс (баланс, смена, план, моменты) сохраняется в `user://save.cfg`.
- `scripts/call_session.gd` — один звонок. Модель играет клиента и после каждой
  твоей фразы возвращает `{"reply", "trust_delta"}`. Доверие 0..100; на 0 клиент бросает трубку.
- Цена: клиент соглашается на сумму, которую ты назвал в разговоре (не больше своего бюджета), её и списывает терминал.
- Клиент может бросить трубку в любой момент.
- Вместо карты можно продиктовать корпоративный номер (+7 900 555-01-23): согласившийся клиент переводит договорённую сумму, она идёт в план.
- Смена = 8 звонков, план первой смены 15 000 ₽, каждая выполненная смена поднимает план на 30%.
- Просьба о карте распознаётся в обычной реплике. Шанс, что клиент пришлёт номер, равен доверию в процентах.
  Номер карты генерирует игра, а не модель, поэтому он всегда корректный.
  Отказ стоит −10 доверия.
- `scripts/desktop.gd` — вертикальный экран для телефона: карточка клиента, шкала доверия,
  переписка, поле ввода с микрофоном, крупные кнопки, главное меню. PayTerminal выезжает снизу: вводишь продиктованный
  номер, жмёшь «Списать» на договорённую сумму в рублях, баланс растёт.
- Ключ для APK вшивается при сборке в `scripts/embedded_key.gd` (файл в .gitignore, в git его нет).

## Модель
`google/gemma-4-26b-a4b-it`: ~1 секунда на реплику, JSON без ошибок в тестах, живой русский.
Цена около $0.00003 за реплику, то есть тысяча реплик стоит примерно 3 цента.
Модель задаётся константой `MODEL` в `scripts/openrouter_client.gd`.
Запасной вариант: `google/gemini-2.5-flash-lite`.
