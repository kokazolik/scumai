# Контора: прототип звонков с ИИ (Godot 4, 2D)

## Скачать APK
Готовая сборка для Android: [apk/kontora-0.4.apk](https://github.com/kokazolik/scumai/raw/main/apk/kontora-0.4.apk).
Открой ссылку с телефона, установи (разреши установку из неизвестных источников), при первом запуске скопируй ключ OpenRouter и нажми «Вставить ключ из буфера».

## Как запустить
1. Открой папку в Godot 4.3+ (Import → `project.godot`).
2. Дай игре ключ OpenRouter одним из способов:
   - переменная окружения `OPENROUTER_API_KEY`;
   - файл `secrets.cfg` в папке пользователя Godot (`user://`, в Windows это
     `%APPDATA%\Godot\app_userdata\Контора\`):
     ```
     [openrouter]
     api_key="sk-or-v1-..."
     ```
   Не клади ключ в папку проекта: он уедет в git и в собранную игру.
3. Запусти (F5). Сразу звонит первый клиент.

## Как устроено
- `scripts/openrouter_client.gd` — автозагрузка `LLM`, `await LLM.chat(messages)`.
- `scripts/callers.gd` — профили звонящих: кто, откуда узнал номер, зачем звонит, характер, стартовое доверие.
- `scripts/call_session.gd` — один звонок. Модель играет клиента и после каждой
  твоей фразы возвращает `{"reply", "trust_delta"}`. Доверие 0..100; на 0 клиент бросает трубку.
- Просьба о карте распознаётся в обычной реплике. Шанс, что клиент пришлёт номер, равен доверию в процентах.
  Номер карты генерирует игра, а не модель, поэтому он всегда корректный.
  Отказ стоит −15 доверия.
- `scripts/desktop.gd` — вертикальный экран для телефона: карточка клиента, шкала доверия,
  переписка, быстрые фразы, крупные кнопки. PayTerminal выезжает снизу: вводишь продиктованный
  номер, жмёшь «Списать $200», баланс растёт.
- Ключ для APK вшивается при сборке в `scripts/embedded_key.gd` (файл в .gitignore, в git его нет).

## Модель
`google/gemma-4-26b-a4b-it`: ~1 секунда на реплику, JSON без ошибок в тестах, живой русский.
Цена около $0.00003 за реплику, то есть тысяча реплик стоит примерно 3 цента.
Модель задаётся константой `MODEL` в `scripts/openrouter_client.gd`.
Запасной вариант: `google/gemini-2.5-flash-lite`.
