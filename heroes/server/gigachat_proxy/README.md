# Сервер-посредник GigaChat (Yandex Cloud Functions)

Телефон не умеет проверять сертификаты Сбера, а этот посредник умеет. Игра отправляет запрос ему, а он передаёт его в GigaChat.
Ключ лежит в настройках функции, а не в игре, поэтому игру можно раздавать людям, у которых своего ключа нет.

## Как поставить (с телефона, минут 15)
1. Скачай `gigachat_proxy.zip` из этой папки (кнопка «Download raw file» на GitHub).
2. console.yandex.cloud → иконка карты справа вверху: должен быть платёжный аккаунт «Активен» или «Пробный период».
3. Меню → «Все сервисы» → «Resource Manager» → нажми на облако (уровень выше папки default).
4. «Права доступа» → «Назначить роли» → себя → роль **admin** → «Сохранить».
   Если кнопка неактивна — «Создать облако», привязать к нему платёжный аккаунт и работать в нём.
5. Меню → «Cloud Functions» → «Создать функцию», имя `chronicles-gigachat`.
6. Включи «Публичная функция».
7. «Редактор»: среда **python312**; способ **ZIP-архив** (`gigachat_proxy.zip`); точка входа `index.handler`;
   таймаут 60, память 128 МБ; переменные окружения `GIGACHAT_AUTH_KEY` = ключ авторизации Сбера,
   `APP_TOKEN` = придуманный пароль латиницей.
8. «Сохранить изменения», подождать сборку версии.
9. «Обзор» → скопировать «Ссылка для вызова» (`https://functions.yandexcloud.net/d4e…`).
10. Дописать `#пароль`: `https://functions.yandexcloud.net/d4eXXXX#пароль`, скопировать целиком.
11. В игре «Ключ ИИ: вставить из буфера» → «Адрес сервера GigaChat сохранён».

Если ссылку вшить в игру (константа `DEFAULT_GC_PROXY` в `scripts/llm.gd`), у всех игроков ИИ заработает без настройки,
но все они будут тратить твои токены.
